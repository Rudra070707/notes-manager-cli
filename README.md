# 📝 Notes Manager CLI

A command-line Notes Manager built with Node.js that stores notes in a JSON file.

---

## Features

- ✅ Add Notes
- ✅ List Notes
- ✅ Delete Notes
- ✅ Search Notes
- ✅ Prevent Duplicate Notes
- ✅ Input Validation
- ✅ Modular Architecture

---

## Technologies Used

- Node.js
- JavaScript (ES6)
- File System (fs)
- JSON
- Git
- GitHub

## Available Commands

### Add Note

```bash
node index.js add "Learn Docker"
```

### List Notes

```bash
node index.js list
```

### Delete Note

```bash
node index.js delete 3
```

### Search Notes

```bash
node index.js search "Express"
```
